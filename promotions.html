การได้รับคูปอง
ในแต่ละสัปดาห์ หากมียอดสะสมเดิมพันที่มีผลในค่ายเกมต่าง ๆ ตรงตามเงื่อนไขที่กำหนด จะสามารถรับคูปองได้ทุกวันจันทร์หลัง 00:30 น. (GMT+8) และสามารถเข้าร่วมกิจกรรมจับรางวัลลุ้นโชคและมีสิทธิ์ได้รับรางวัลโบนัสสูงสุด!

ตัวอย่างคำอธิบาย
  • 1.ทุกสัปดาห์เมื่อสะสมยอดเดิมพันที่มีผลใน 3D สล็อต ครบ 5,000 จะได้รับคูปอง 1 ใบ และหากสะสมยอดเดิมพันได้ถึง 15,000 จะได้รับคูปองเพิ่มอีก 1 ใบ รวมทั้งหมด 2 ใบ
  • 2.ทุกสัปดาห์เมื่อสะสมยอดเดิมพันที่มีผลใน 3D สล็อต ครบ 30,000 จะได้รับคูปอง 3 ใบ และทุกครั้งที่สะสมยอดเดิมพันครบ 30,000 จะได้รับคูปองเพิ่มอีก 1 ใบ ไม่จำกัดคูปอง
  • ทุกสัปดาห์เมื่อสะสมยอดเดิมพันที่มีผลในค่ายใดค่ายหนึ่งถึง 20,000 จะได้รับคูปองทั้งหมด 2 ใบ
  • ทุกสัปดาห์เมื่อสะสมยอดเดิมพันที่มีผลในค่ายใดค่ายหนึ่งถึง 50,000 จะได้รับคูปองทั้งหมด 3 ใบ
  • ทุกสัปดาห์เมื่อสะสมยอดเดิมพันที่มีผลในค่ายใดค่ายหนึ่งถึง 100,000 จะได้รับคูปองทั้งหมด 5 ใบ
  • ดังนั้นทุกสัปดาห์หากสะสมยอดเดิมพันที่มีผลในค่ายใดค่ายหนึ่งถึง 1,000,000 จะได้รับคูปองทั้งหมด 35 ใบ (ไม่จำกัด)
ข้อควรระวัง
  • 1. หลังการจับรางวัลสิ้นสุดลง โปรดกด (รับโบนัส) ด้วยตัวเองในหน้ากิจกรรมของค่ายเกมนั้น ๆ ภายใน 24 ชม. หากเกินเวลาดังกล่าว จะถือว่าสละสิทธิ์ในการรับโบนัส
  • 2. ช่วงเวลากิจกรรมของแต่ละสัปดาห์ระบบจะนับและคำนวณบัญชีที่มียอดสะสมเดิมพันโดยอัตโนมัติ ยอดเดิมพันสะสมดังกล่าวจะคำนวณและยึดตามค่ายนั้น ๆ เป็นหลัก รายละเอียดสามารถเข้าไปอ่านเพิ่มเติมตามค่ายเกมต่าง ๆ ที่เกี่ยวข้องได้ในข้อควรระวัง
  • 3. การเดิมพันที่มีผลแพ้-ชนะทั้งหมด จะถูกบันทึกเป็นยอดสะสมเดิมพันในแต่ละค่าย ในกรณีที่มีการเดิมพันเสมอ เดิมพันสองฝั่ง ยกเลิกการวางเดิมพัน รวมไปถึงการวางเดิมพันที่ไม่มีความเสี่ยง จะไม่ถูกคำนวณเป็นยอดเดิมพันสะสม
  • 4. คูปองแต่ละใบสามารถรับรางวัลได้เพียง 1 รางวัล ซึ่งเงินโบนัสจะต้องสอดคล้องกับเงื่อนไขการถูกรางวัลสูงสุด
  • 5. ในกรณีที่เกิดเหตุสุดวิสัย เช่น การปิดปรับปรุงเว็บไซต์ หรือระบบเกิดความขัดข้อง เป็นเหตุให้ไม่สามารถออกผลรางวัลตามงวดที่กำหนดไว้ได้ ทางบริษัทจะประกาศเกณฑ์การออกรางวัลให้ทราบอีกครั้ง และจะทำการจ่ายเงินรางวัลโดยยึดตามผลลัพธ์สุดท้ายเป็นหลัก
  • 6. โบนัสที่ได้รับจากกิจกรรม ไม่มีข้อจำกัดในการทำยอดเทิร์นโอเวอร์ สมาชิกสามารถใช้โบนัสในการเล่นเกมหรือถอนได้ทันที
  • 7. หากบริษัทตรวจพบบุคคลหรือกลุ่มคนที่ใช้สิทธิ์ของบริษัทไปในทางที่ไม่ถูกต้อง ทางบริษัทขอสงวนสิทธิ์ในการยกเลิกและเรียกคืนสิทธิ์ดังกล่าว
  • 8.ทุกกิจกรรมทางเราได้จัดขึ้นมาเป็นพิเศษเพื่อสมาชิกโดยเฉพาะ หากมีข้อโต้แย้งใด ๆ เกี่ยวกับเงื่อนไขของกิจกรรม เพื่อรักษาผลประโยชน์ของทั้งสองฝ่าย บริษัทขอสงวนสิทธิ์ในการเรียกร้องให้ลูกค้าจัดเตรียมข้อมูลหรือรูปภาพต่าง ๆ ที่เกี่ยวข้อง เพื่อยืนยันและพิจารณาว่าสมาชิกมีคุณสมบัติตรงตามเงื่อนไขในการเข้าร่วมกิจกรรมพิเศษต่าง ๆ
  • 9. ครอบครัวเดียวกัน / ที่อยู่ตามทะเบียนบ้านเดียวกัน / ที่อยู่อีเมลเดียวกัน / หมายเลขโทรศัพท์เดียวกัน / บัญชีธนาคารเดียวกัน / ที่อยู่ IPเดียวกัน / คอมพิวเตอร์เครื่องเดียวกัน / จำกัดสิทธิ์การเข้าร่วมได้เพียง 1 บัญชีเท่านั้น
  • 10. ถ้าหากกิจกรรมมีการเปลี่ยนแปลงใดๆ ทางบริษัทมีสิทธิ์ในการแก้ไข ระงับ หรือยกเลิกกิจกรรมได้ตลอดเวลา และทางบริษัทขอสงวนสิทธิ์ในการเป็นผู้อธิบายกิจกรรมนี้แต่เพียงผู้เดียวเท่านั้น

ข้อควรระวัง
  • 1.
    หลังจากที่ได้ทำการฝากเงินแล้ว ยอดเทิร์นโอเวอร์ถึงเกณฑ์ที่กำหนด(ยอดฝากเงิน+โบนัสที่ได้รับ)*จำนวนเท่าตัวของยอดเทิร์นโอเวอร์จึงจะทำการถอนเงินได้ ถ้าหากยอดเทิร์นโอเวอร์ไม่ถึงเกณฑ์ที่กำหนด ทางเราจะริบเงินโบนัสและเงินเดิมพันชนะทั้งหมด (กรณีเดิมพันทั้งสองข้างจำนวนเงินเดิมพันนี้จะไม่มีผลต่อการทำยอดเงินสะสมจากการเล่น)
    • ตัวอย่างการฝากครั้งแรก：
    • ตัวอย่างที่ 1：
      ฝากเงิน 100 จะได้โบนัส 100 จำเป็นต้องลงเดิมพัน (100+100)*3=600 ยอดเทิร์นโอเวอร์ถึงจะสามารถทำการถอนเงินได้
    • ตัวอย่างที่ 2：
      ฝากเงิน 2000 จะได้โบนัสสูงสุด 1000 จำเป็นต้องมียอดเทิร์นโอเวอร์ถึง (1000+1000)*3=6000 เพิ่มส่วนต่างของเงินฝาก (2000-1000)*1=1000 จะต้องมียอดเทิร์นโอเวอร์ถึง 7000 ถึงจะสามารถทำการถอนเงินได้
  • 2.
    สามารถลงเดิมพันได้ทุกเกม เพียงแค่เป็นการเดิมพันที่มีผลแพ้ชนะจะนับเป็นยอดเดิมพันที่มีผลทั้งหมด หากมียอด
    เทิร์นครบตามเงื่อนไขก็สามารถทำการถอนเงินได้
  • 3.
    การรับโบนัสคุณจำเป็นต้องกด (สมัครทันที)หลังจากที่ได้ทำการฝากเสร็จสมบูรณ์ เพื่อยื่นเรื่องการสมัคร หลังจากที่ยื่นเรื่องการสมัครแล้วระบบจะทำการตรวจสอบให้เสร็จสิ้นภายใน3 ชั่วโมง
  • 4.
    บัญชีเดียวกัน / ครอบครัวเดียวกัน / ที่อยู่ตามทะเบียนบ้านเดียวกัน / ที่อยู่อีเมลเดียวกัน / หมายเลขโทรศัพท์เดียวกัน / บัญชีการชำระเงินเดียวกัน (เช่น บัญชีเดบิต / บัตรเครดิต ฯลฯ ) / ที่อยู่ IP เดียวกัน / คอมพิวเตอร์เครื่องเดียวกันสามารถสมัครโปรโมชันได้แค่ครั้งเดียวเท่านั้น
  • 5.
    ทางบริษัทมีสิทธิ์ในการตัดสินว่าสมาชิกทำการเดิมพันที่มีความผิดปกติหรือทำการเดิมพันที่ไม่มีความเสี่ยงเพื่อหาผลประโยชน์จากกิจกรรมโปรโมชันหรือไม่ ทางบริษัทจะตรวจตราพฤติกรรมของสมาชิกอย่างเคร่งครัด และ หากตรวจพบสมาชิกทำการหลอกลวงหรือหาผลประโยชน์จากกฎข้อบังคับและเงื่อนไขของบริษัทเพื่อที่จะได้มาซึ่งผลกำไรที่ผิดกฎหมาย หรือไม่ว่าจะเป็นการละเมิดใดๆก็ตาม ทางบริษัทมีสิทธิ์ในการยุติการเข้าสู่ระบบของสมาชิก ระงับสิทธิ์การใช้งานเว็บไซต์ของสมาชิกชั่วคราว รวมไปถึงมีสิทธิ์ยึดโบนัสและผลกำไรของสมาชิกโดยไม่จำเป็นต้องแจ้งให้ทราบล่วงหน้า
  • 6.

    การรับโบนัสคุณจำเป็นต้องกด (สมัครทันที)หลังจากที่ได้ทำการฝากเสร็จสมบูรณ์ เพื่อยื่นเรื่องการสมัคร หลังจากที่ยื่นเรื่องการสมัครแล้วระบบจะทำการตรวจสอบให้เสร็จสิ้นภายใน3 ชั่วโมง
  • 4.
    บัญชีเดียวกัน / ครอบครัวเดียวกัน / ที่อยู่ตามทะเบียนบ้านเดียวกัน / ที่อยู่อีเมลเดียวกัน / หมายเลขโทรศัพท์เดียวกัน / บัญชีการชำระเงินเดียวกัน (เช่น บัญชีเดบิต / บัตรเครดิต ฯลฯ ) / ที่อยู่ IP เดียวกัน / คอมพิวเตอร์เครื่องเดียวกันสามารถสมัครโปรโมชันได้แค่ครั้งเดียวเท่านั้น
  • 5.
    ทางบริษัทมีสิทธิ์ในการตัดสินว่าสมาชิกทำการเดิมพันที่มีความผิดปกติหรือทำการเดิมพันที่ไม่มีความเสี่ยงเพื่อหาผลประโยชน์จากกิจกรรมโปรโมชันหรือไม่ ทางบริษัทจะตรวจตราพฤติกรรมของสมาชิกอย่างเคร่งครัด และ หากตรวจพบสมาชิกทำการหลอกลวงหรือหาผลประโยชน์จากกฎข้อบังคับและเงื่อนไขของบริษัทเพื่อที่จะได้มาซึ่งผลกำไรที่ผิดกฎหมาย หรือไม่ว่าจะเป็นการละเมิดใดๆก็ตาม ทางบริษัทมีสิทธิ์ในการยุติการเข้าสู่ระบบของสมาชิก ระงับสิทธิ์การใช้งานเว็บไซต์ของสมาชิกชั่วคราว รวมไปถึงมีสิทธิ์ยึดโบนัสและผลกำไรของสมาชิกโดยไม่จำเป็นต้องแจ้งให้ทราบล่วงหน้า
  • 6.
    ถ้าหากกิจกรรมมีการเปลี่ยนแปลงใดๆ ทางบริษัทมีสิทธิ์ในการแก้ไข ระงับ หรือยกเลิกกิจกรรมได้ตลอดเวลา

  • พัดลมความเย็นแบบพกพาพับได้

    รายละเอียดผลิตภัณฑ์พัดลมแบบพกพาที่จะมอบประสบการณ์ความเย็นที่คุณต้องลอง
    ออกแบบมาให้พับได้ สะดวกต่อพกพาและจัดเก็บได้ง่าย ตัวเครื่องมีหน้าจออิเล็กทรอนิกส์แสดงระดับแบตเตอรี่ และมาพร้อมกับโมดูลทำความเย็นด้วยการแช่แข็งที่มีความเร็วสูง สามารถปรับความเร็วลมได้ตามต้องการ ตั้งแต่ลมเบา ๆ ไปจนถึงลมเย็นแรง ๆ สลับได้ตามใจชอบ เพื่อให้ความเย็นต่อเนื่องไม่ขาดตอน

    ข้อมูลจำเพาะขนาด: 6 * 5.2 * 17.3 ซม.
    น้ำหนัก: 230 กรัม
    พลังงานพัดลม: ≤10W
    ความจุแบตเตอรี่: 4000 mAh
    ระยะเวลาใช้งาน: ประมาณ 2 ชั่วโมง
    ประเภทพอร์ต: TYPE-C

  • มินิพาวเวอร์แบงค์แบบแม่เหล็ก

    รายละเอียดผลิตภัณฑ์ขนาดเล็กจิ๋วพอดีฝ่ามือ มาพร้อมผิวสัมผัสแบบโลหะด้านที่เข้ากันได้ดีกับรูปลักษณ์ที่เรียบง่าย
    ดีไซน์แบบแม่เหล็กดูดติดได้ แค่แปะก็ชาร์จ ไม่ต้องใช้สายไฟให้ยุ่งยาก
    รองรับเทคโนโลยีชาร์จเร็วและการปรับกำลังไฟอย่างชาญฉลาด เพื่อให้มั่นใจในการชาร์จโทรศัพท์ได้อย่างปลอดภัยและมีประสิทธิภาพ

    ข้อมูลจำเพาะขนาดผลิตภัณฑ์: 9.3 x 14.3 x 1.9 ซม.
    น้ำหนักผลิตภัณฑ์: 160 กรัม
    ความจุแบตเตอรี่: 5000 mAh
    เวลาในการชาร์จ: ประมาณ 2.5 ชั่วโมง
    ประเภทอินเทอร์เฟซ: TYPE-C

  • สมาร์ทวอทช์มอนิเตอร์อัจฉริยะ

    รายละเอียดผลิตภัณฑ์สมาร์ทวอทช์"ฟังก์ชันครบครัน ผสานรวมเป็นหนึ่ง"
    ตัวเรือนทำจากโลหะผสมและหน้าจอขนาดใหญ่ 1.96 นิ้วความละเอียดสูง รองรับการใช้งานแบบสัมผัสและสลับธีมได้หลากหลาย การเชื่อมต่อบลูทูธแบบสองโหมดที่รวดเร็ว ทำให้การโทรชัดเจนและลื่นไหล
    มีฟังก์ชันการตรวจสอบอัตราการเต้นของหัวใจ, ความดันโลหิต, ระดับออกซิเจนในเลือด, ความเครียด, อารมณ์ และการนอนหลับ ผสมผสานกับการฝึกสุขภาพและการหายใจ ทำให้คุณสามารถตรวจสอบสภาพร่างกายของคุณได้ตลอดเวลา และยังมาพร้อมกับผู้ช่วยเสียงอัจฉริยะ, บันทึกการออกกำลังกาย, ขอความช่วยเหลือฉุกเฉิน (SOS) และการออกแบบที่ใช้พลังงานต่ำ ทำให้ตอบสนองความต้องการด้านไลฟ์สไตล์อัจฉริยะของคุณได้อย่างครบถ้วน

    ข้อมูลจำเพาะขนาดผลิตภัณฑ์: 24 x 28.2 ซม.
    ขนาดหน้าจอ: 1.96 นิ้ว
    วัสดุผลิตภัณฑ์: โลหะผสม + พลาสติก
    ระบบที่รองรับ: Android 4.4, iOS 9.0 และเวอร์ชันที่สูงกว่า
    เวอร์ชันบลูทูธ: V5.2
    ระดับการกันน้ำ: IP67
    ระยะเวลาการใช้งานแบตเตอรี่: สแตนด์บาย 30 วัน, ใช้งานปกติ 3-7 วัน (อาจแตกต่างกันไปตามลักษณะการใช้งานของแต่ละบุคคล)

  • หูฟังบลูทูธแบบคล้องหู

    รายละเอียดผลิตภัณฑ์การออกแบบตามหลักสรีรศาสตร์แบบเกี่ยวหูที่กระชับมั่นคง ไม่ลื่นหลุด ทำให้คุณภาพเสียงไม่สะดุดแม้เล่นกีฬาหนัก, รองรับ Bluetooth เวอร์ชั่นล่าสุดและฟังก์ชันตัดเสียงรบกวนอัจฉริยะเพื่อการสนทนาที่ชัดเจนและเพลงที่บริสุทธิ์, แบตเตอรี่ใช้งานได้ยาวนาน และเมื่อเปิดกล่องเก็บประจุสามารถเชื่อมต่อได้ทันที เหมาะสำหรับทั้งการออกกำลังกาย, ขับรถ, เดินทาง หรือทำงาน เป็นอุปกรณ์ที่ช่วยเพิ่มทั้งสไตล์และประสิทธิภาพให้กับคุณ

    ข้อมูลจำเพาะขนาดผลิตภัณฑ์:
    หูฟัง (แต่ละข้าง): 3.17 x 1.9 x 1.84 ซม.
    เคสชาร์จ: 5.76 x 2.81 x 5.17 ซม.
    น้ำหนักผลิตภัณฑ์:
    หูฟัง (แต่ละข้าง): 5.4 กรัม
    เคสชาร์จ: 35 กรัม
    เวอร์ชันบลูทูธ: V5.4
    ระดับการกันน้ำ: IPX5 (กันน้ำสำหรับใช้งานในชีวิตประจำวัน)
    อายุการใช้งานแบตเตอรี่:
    สแตนด์บาย: 80 ชั่วโมง
    เล่นเพลง: ประมาณ 5 ชั่วโมง (ที่ระดับเสียงสูงสุด)

  • ลำโพงบลูทูธกันน้ำ

    รายละเอียดผลิตภัณฑ์ลำโพงพกพาขนาดกะทัดรัดและทนทาน ดีไซน์ลำโพงคู่แบบสเตอริโอ ให้เสียงเบสที่ทุ้มนุ่มลึก และคุณภาพเสียงที่ใสเคลียร์มีมิติ
    ตัวเครื่องกันน้ำกระเด็นสามารถใช้งานกลางแจ้งที่มีความชื้นและฝนตกปรอยๆ ได้อย่างสบาย แบตเตอรี่ใช้งานได้ยาวนานถึง 8 ชั่วโมง
    ตอบโจทย์การใช้งานได้หลายโอกาส เช่น การตั้งแคมป์ ชายหาด ปิกนิก และอื่นๆ ให้คุณเพลิดเพลินกับเสียงเพลงได้ทุกที่ทุกเวลา มอบพลังงานที่ไม่สิ้นสุดและจังหวะแห่งอิสระ

    ข้อมูลจำเพาะขนาดผลิตภัณฑ์: 18 x 4.3 x 6.3 ซม.
    น้ำหนักผลิตภัณฑ์: 540 กรัม
    เวอร์ชันบลูทูธ: V5.3
    ระดับการกันน้ำ: IPX5
    รองรับการ์ดหน่วยความจำ: สูงสุด 32GB
    ระยะเวลาการใช้งานแบตเตอรี่: ประมาณ 7-8 ชั่วโมง

  2. ไม่ว่าจะเป็นบุคคลหรือกลุ่มบุคคลหากมีการใช้สิทธิพิเศษของบริษัทในทางที่ผิด ทางบริษัทขอสงวนสิทธิ์ในการยกเลิกและเพิกถอนสิทธิพิเศษหลังจากที่ทางบริษัทได้ทำการตรวจสอบบัญชีแล้ว
  3. กิจกรรมทั้งหมดได้ออกแบบมาเป็นพิเศษเพื่อผู้เล่นโดยเฉพาะ ในกรณีที่ผู้เล่นกรอกข้อมูลลงทะเบียนแล้วมีข้อโต้แย้ง เพื่อรับประกันผลประโยชน์ของทั้งสองฝ่ายและกำจัดการขโมยข้อมูลส่วนตัว ทางบริษัทขอสงวนสิทธิ์ขอความกรุณาลูกค้าจัดหาไฟล์ภาพที่มีความเหมาะสมเพียงพอและมีประสิทธิภาพ และอีกหลายวิธีในการระบุว่าลูกค้ามีสิทธิ์ได้รับข้อเสนอพิเศษของเราหรือไม่
  4. บัญชีเดียวกัน / ครอบครัวเดียวกัน / ที่อยู่ตามทะเบียนบ้านเดียวกัน / ที่อยู่อีเมลเดียวกัน / หมายเลขโทรศัพท์เดียวกัน / บัญชีการชำระเงินเดียวกัน (เช่น บัญชีเดบิต / บัตรเครดิต ฯลฯ ) / ที่อยู่ IP เดียวกัน / คอมพิวเตอร์เครื่องเดียวกันสามารถสมัครโปรโมชันได้แค่ครั้งเดียวเท่านั้น
  5. ถ้าหากกิจกรรมมีการเปลี่ยนแปลงใดๆ ทางบริษัทมีสิทธิ์ในการแก้ไข ระงับ หรือยกเลิกกิจกรรมได้ตลอดเวลา
